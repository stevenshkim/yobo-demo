## Testing plan
1. **Start with retargeting** (site/audit/content audiences) — cheapest, validates creative.
2. Test the **teardown** and **leaky-bucket** angles first (highest expected CTR).
3. Many creatives, few ad sets; conversion event = audit/trial start.
4. **Kill/scale rule:** kill an ad set if CAC > target after [statistically meaningful spend];
   scale winners while payback < ~1 month. Reserve cold prospecting until trial→paid ≥ 20%.

> **Log to `os/funnels/01-lead-generation.md`:** CAC + trial→paid by ad set / angle / segment;
> winning hook + visual; which community-lane creative wins. Kill losers fast to protect the blend.
