# Execution Calendar — First 2 Weeks (Tuesday start)

> The operational glue: who does what, in what order, to go from "OS drafted" to "engine running."
> Sequenced so foundation + the cheapest customers come first. Ties the build plan
> (`os/gtm-build-plan.md`) + decisions (`os/DECISIONS-NEEDED.md`) to a schedule.

## Day 1 (Tuesday) — unblock + kick off
- **Founder:** resolve the P0 decisions (`DECISIONS-NEEDED.md`): reconcile pricing, confirm trial
  design, name 5 design-partner brands, hand over real proof numbers (→ `proof-library.md`).
- **Dev:** scope + start A1 (UTM capture → CRM) and trial gating + Win-Back-for-all-types.
- **Ops:** **buy secondary domains + start mailbox warming today** (it takes 2–4 weeks — every day
  of delay pushes cold outbound later). Follow `os/integrations/deliverability-playbook.md`.
- **Everyone:** read `TEAM-KICKOFF.md`; adopt the daily Slack standup + weekly pace review.

## Days 2–5 (Week 1) — Wave 1 (warm) + build foundation
- **Growth:** launch the **Wave-1 warm-list sequence** (`campaigns/wave-1-warm-list-activation.md`)
  — no deliverability dependency, cheapest first customers. Drive audit claims.
- **Content:** spin up **lane 1 (general teardowns)** + the **founder account**; shoot the 8 starter
  scripts (`campaigns/content-engine.md`); set up a scheduler.
- **Dev:** CRM stages/fields/automations; product-analytics events; begin the 7-day Shopify match.
- **CS:** prep onboarding + the weekly-recap template for the first trials.
- **Founder:** open warm intros to the 5 design partners; book any sales-assist demos.
- **Gate watch:** start measuring **trial→paid** as the first warm trials convert.

## Days 6–10 (Week 2) — prove, then prep scale
- **Growth:** nurture warm trials → paid (activation nudges + BOFU sequence); start building the
  Wave-2 outbound lists (the cold *sequences* are ready; sending waits on warming).
- **Content:** daily posting on lane 1 + founder; add **lane 2 (Latina beauty)**; log audit-clicks
  by hook/lane; clone the winning hook.
- **Dev:** finish attribution match + trial billing (charge-then-auto-credit + guarantee credit).
- **Founder/Sales:** run sales-assist on $5–20M / stalled high-intent (`campaigns/sales-assist-playbook.md`).
- **Weekly pace review (`/funnel-metrics-review`):** first real on-pace/off-pace call vs the
  **Jun 15 = $20k MRR** checkpoint; name the binding constraint; pick the one big lever.

## Gates before scaling (don't skip)
- **Trial→paid ≥ 20%** before scaling paid prospecting (`gtm-build-plan.md` C5).
- **Deliverability ready** (domains warmed ≥ 2 wks) before any cold-outbound volume.
- **Attribution live** before trusting CAC-by-channel decisions.

## Then (Week 3+) — scale the winners
Turn on paid (retargeting → high-intent → prospecting), scale outbound on warmed domains, ramp
content lanes 3–5, open partnerships, stand up the CS recap engine. Reallocate weekly to the
lowest-CAC channel. Pace daily vs the MRR checkpoints (`ops/metrics-dashboard.md`).

## Standing cadence (from day 1)
- **Daily (Slack, 5 min):** trials by channel · new MRR · at-risk · today's #1 lever.
- **Weekly (30 min):** `/funnel-metrics-review` → update `metrics-dashboard.md` → log the decision.
- **Always:** end every session with "log what we learned."
