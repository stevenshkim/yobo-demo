## Operating cadence (`os/ops/operating-cadence.md`)
- **Daily (Slack, 5 min):** trials started (by channel) · new MRR · at-risk customers · today's #1 lever.
- **Weekly (30 min):** run `/funnel-metrics-review` — state on-pace/off-pace vs the MRR checkpoint,
  name the binding constraint (volume / trial→paid / ACV mix / CAC), pick the one big lever, log it.
- **Always:** end every session with "log what we learned" — the repo is our memory; that's what compounds.

## The rule that makes this work
**Context before craft · tie every task to a metric · change strategy in the file first · commit every learning.**
A session that ends without writing something back taught us nothing.
